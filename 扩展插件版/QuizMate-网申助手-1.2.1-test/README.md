# QuizMate 网申助手 2026.9.9

自动化网申永久免费。沿用 QuizMate 账号和后台 AI 配置；插件端不维护模型地址或 API Key，网申 AI 配置、字段映射和站点热规则由后台统一管理。

1. 解压 ZIP，在 Chrome/Edge 扩展管理页打开开发者模式，选择“加载已解压的扩展程序”，选中含 manifest.json 的文件夹。
2. 右键插件图标 → 选项，或在招聘网页点击插件图标 → 维护简历。
3. 新安装已内置一份全字段虚构示例简历，未登录也可扫描页面并用本地通用规则试填；登录后启用后台 AI 和站点热规则。
4. 手动维护简历，或点击“AI 解析文件”。支持文本型 PDF、DOCX、TXT、MD；扫描 PDF 请转成 PNG/JPEG/WebP 后使用支持图片的模型。
5. 打开网申页，点击插件图标 → 扫描表单 → 开始 AI 填写。检查后自行提交。

模型支持图片时可打开“模型支持图片”发送截图辅助匹配，纯文本模型保持关闭。执行 AI 功能时相关资料发送到指定服务商。

默认只填空白项，AI 失败时使用本地规则。不同招聘站点的复杂控件仍需实际测试。

AI 请求通过 QuizMate 后台账号鉴权转发，插件安装包不包含模型密钥。
