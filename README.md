# QuizMate 产品仓库

当前有效产品和资料统一位于本仓库，不再从 `秋招助手` 目录开发或发布。

1. `官网模块`：生产官网和官网下载文件。
2. `注册登陆模块`：生产 API、统一入口、账号、积分、充值和支付。
3. `windows客户端`：Windows 笔试助手与面试助手。
4. `desktop-core`：Windows / Mac 共用的桌面核心能力。
5. `邀请注册机制`：邀请注册、奖励和代理机制设计入口；运行代码位于生产后端。
6. `域名售卖页`：独立域名售卖页面。
7. `mac客户端`：Mac 客户端源码，与 Windows 共享 `desktop-core`。
8. `扩展插件版`：免费的 AI 网申、投递管理和职位监控浏览器插件。
9. `安卓端`：仅包含笔试助手的 Android 客户端。
10. `运营管理`：2026-07-25 之后的运营资料及当前品牌/教程素材。
11. `测试文档`：当前版本测试资料。
12. `其他`：部署工具、规范、技能和目录整理记录。

`归档l历史代码正常不需要引用` 只保存历史文件，不参与编译、发布和运行，可在确认无回滚需要后整体删除。
