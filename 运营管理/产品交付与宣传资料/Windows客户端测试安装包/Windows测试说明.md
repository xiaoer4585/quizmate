# QuizMate Windows 1.1.0 内部测试说明

## 安装包

- 文件：`QuizMate-Windows-1.1.0-x64-20260715.exe`
- 系统：Windows 10/11 x64
- 类型：NSIS 当前用户安装包
- 签名：内部测试包未配置代码签名，Windows 可能显示“未知发布者”
- 后端：保持原 CloudBase 账号、积分、分析和知识库接口；未接入暂停的新阿里云 API
- 回滚包：`QuizMate-Windows-1.0.0-x64-20260714.exe` 仍保留，不覆盖

## 建议测试顺序

1. 安装并启动，确认首屏为“登录积分账号”，没有序列号激活入口。
2. 点击“注册账号”和“忘记密码”，确认仍打开原 CloudBase 账号页。
3. 使用积分账号登录，确认右上角显示积分余额和单次成功消耗。
4. 使用“选择图片”完成一次分析，确认结果与积分余额正确。
5. 使用“截取屏幕”和 `Ctrl + Shift + Y`，确认截图预览、取消和提交正常。
6. 模拟错误图片、断网或取消，确认界面提示未扣积分。
7. 退出并重新启动，确认会话恢复符合预期；退出账号后确认会话清除。
8. 在“设置”中录入新快捷键、保存、重启并恢复默认，冲突时确认保留旧快捷键。
9. 开启悬浮答案，最小化/隐藏主窗口，检查透明度、拖动、复制、返回主窗口和隐藏；正常截图/录屏应能看到悬浮内容。
10. 打开“知识库”，验证支持格式、4 MB 上限、上传、列表、删除和分析命中提示。
11. 卸载并重新安装，确认安装、快捷方式和卸载项正常；如需回滚，先卸载 1.1.0 再安装保留的 1.0.0。
