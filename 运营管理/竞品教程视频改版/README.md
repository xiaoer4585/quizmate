# 竞品教程视频品牌适配

状态：竞品原片已下载并校验，Windows 与 macOS 品牌适配版已生成；最终文件校验见本目录的 `来源与改版说明.md`。

## 目录

- `01_竞品原片`：从竞品网站下载的两个原始 MP4，永久保留，不覆盖。
- `02_品牌素材`：由用户 Logo 生成的视频顶栏、片头卡和页面品牌覆盖块。
- `03_品牌适配成片`：QuizMate 答题悬浮助手 Windows/macOS 参考成片。
- `_网页资源缓存`：网站脚本缓存、断点下载缓存、转码工具、构建脚本、日志和抽帧检查证据。
- `来源与改版说明.md`：来源 URL、原片哈希、替换项、局限和安全边界。

## 使用说明

成片保留原视频的操作顺序和音频，通过顶部品牌栏、页面左上角覆盖块和片头卡替换主要竞品官网/Logo 露出。由于源视频是压平的屏幕录制，界面内部零散旧名称不能在不破坏教学画面的情况下完整逐元素替换，因此成片标注为“品牌适配参考版”。

正式对外发布时，推荐按该视频的讲解顺序，使用 QuizMate 实际 Windows/macOS 产品重新录屏，再替换本目录中的参考版。
