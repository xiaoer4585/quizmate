# 小红书站外引流完整解决方案

> 更新时间：2026-07-25  
> 痛点：小红书笔记正文**不支持任何形式的可点击站外链接**——所有 URL 都是纯文本，无法点击打开  
> 目标：让用户从笔记直达 https://www.quizmate.vip/

---

## 一、小红书链接规则（先搞懂平台限制）

| 位置 | 是否支持站外链接 | 是否可点击 | 备注 |
|------|---------------|---------|------|
| 笔记正文（图文/视频） | ❌ 不支持 | ❌ 不可点击 | 纯文本，无效 |
| 笔记话题标签 #xxx | ❌ 仅平台内话题 | ❌ 不跳转外网 | |
| 评论区 | ⚠️ 部分被过滤 | ⚠️ 经常被吞 | 别赌运气 |
| **个人主页简介** | ✅ **官方支持** | ✅ **可直接点击** | **唯一 100% 可靠方案** |
| 笔记配图中的二维码 | ✅ 微信/支付宝/相机都可扫 | ✅ 长按识别 | **最直接方案** |

**结论**：只有两条路是 100% 靠谱的——
1. **二维码**（放图片里，用户长按识别）
2. **主页简介**（设置好后引导用户去看）

下面把这两条路打通，并提供组合拳方案。

---

## 二、方案 A：二维码引流（最直接）

### 原理
把 https://www.quizmate.vip/ 生成二维码 → 做成图片上传到笔记 → 用户长按识别 → 直接打开官网。

### 已生成物料

| 文件名 | 尺寸 | 用途 |
|--------|------|------|
| `quizmate_qrcode.png` | 600×600 | 纯二维码（可嵌入其他图） |
| `xhs_guide_1080x1440.png` | 1080×1440 | **小红书竖版引导图（直接当最后一张图上传）** |
| `bh_guide_1200x675.png` | 1200×675 | 百家号横版引导图 |

### 使用方法（小红书）

#### 步骤 1：上传图片
把 `xhs_guide_1080x1440.png` 作为笔记的**最后一张图**上传（最后一张图曝光率最高）。

#### 步骤 2：正文引导文案
在笔记正文末尾加：

```
📌 长按图片识别二维码，直达官网
🔗 或戳我头像 → 看主页简介（可直接点击）
```

#### 步骤 3：评论区置顶（重要）
发笔记后立刻发一条置顶评论：

```
🏷️ 官网链接获取方式：
1️⃣ 长按识别笔记最后一张图中的二维码
2️⃣ 点我头像 → 主页简介里有官网链接（可直接点击）

需要的小伙伴直接去哈，资料齐的~
```

> 💡 评论区是二级流量入口，置顶后所有用户都能看到，相当于"二次曝光"。

### 优势 / 局限

✅ **优势**：100% 可点击跳转；不依赖平台规则；任何平台（小红书/微信/微博/抖音）都通用  
⚠️ **局限**：需要用户多一步操作（长按 → 识别 → 跳转）；不适合强转化场景

## 三、方案 B：主页简介引流（最稳妥）

### 原理
小红书**唯一官方支持站外链接**的位置是「个人主页简介」。在简介里放官网链接，然后在笔记里引导用户"看主页"。

### 设置步骤（5 分钟搞定）

#### 步骤 1：设置主页简介
1. 打开小红书 → 「我」→ 右上角「编辑资料」
2. 找到「简介」字段
3. 填写以下内容（直接复制粘贴）：

```
🎓 QuizMate 答题悬浮助手官网 👇
🔗 https://www.quizmate.vip/
📚 个人知识库 | 6种AI模型 | 不截屏不切屏
💡 戳笔记最后一张图也可直接识别二维码访问
```

> ⚠️ 注意：简介里**只能放 1 个链接**，平台限制。重复或堆链接会被折叠。

#### 步骤 2：笔记正文引导
每篇笔记正文末尾都加：

```
👆 戳我头像 → 看主页简介（官网链接在里面，可直接点击）
```

#### 步骤 3：配合"草稿链接卡片"
小红书发布时可挂"关联笔记/商品"，但不能挂外部链接。所以简介是唯一入口。

### 优势 / 局限

✅ **优势**：100% 可点击；用户进你主页后能看到所有历史笔记；专业感强  
⚠️ **局限**：需要用户先点你头像，路径稍长；对新用户来说发现成本略高

## 四、推荐组合拳（A + B 同时用）

**不要只选一个，两个都上才是最优解。**

### 笔记标准模板（每篇都用）

#### 配图（建议 4-6 张）

```

```

#### 发布后置顶评论
```

1️⃣ 长按识别笔记最后一张图中的二维码（最快）
```

这样用户有**三条路径**进官网：
1. 看图（推荐）→ 长按识别 → 直接跳转
2. 点头像 → 看简介 → 点击链接
3. 看评论区 → 看到指引 → 走上面任一路径

## 八、关于"评论区链接"的补充说明

**有用户反馈评论区放链接也能跳转，但强烈不建议依赖这个：**

1. 小红书会主动**过滤站外链接**，含 `https://`、`http://` 的评论经常被自动折叠或发不出去
2. 评论区规则**经常更新**，今天能发明天可能就被吞
3. 置顶评论本身存在率不是 100%（部分账号无置顶功能）

所以**只把评论区当引流到主页/二维码的"中转站"**，永远不要把评论区当主入口。
