笔试/面试的平台通常是一个独立的软件，又或者是浏览器打开的网页，这些平台受限于电脑系统本身的安全限制，它们在自身权限范围内的检测手段是有限的，QuizMate 可以逐一破解。

1.4 测试检查（重要）

⚠️ 重要提醒
如果你的笔试/面试要求你共享屏幕，那么建议你在正式使用前进行共享屏幕测试，以确保隐身功能生效。

具体测试方式如下：

  1. 请打开你要用来接入会议的平台（例如腾讯会议、Zoom、钉钉、飞书等等），快速开启一个新会议，使用另一台设备（自己的手机或者是其他小伙伴的账号）入会。
  2. 接着启动 QuizMate 笔试/面试助手，然后在会议中共享整个电脑屏幕。
  3. 在另一台设备上，检查你共享的屏幕内容，是否会出现 QuizMate 的界面。如果能看得到，请确认是否符合前面的系统和平台要求，尝试把系统和会议软件升级到最新版本再次尝试。

  3. 安装后打开 QuizMate 客户端并完成登录/注册，新用户会享有免费试用积分。

2.2 权限设置

Mac 用户

  • 在首次打开 QuizMate 时，如果弹出系统确认框，请输入你的系统开机密码，选择"始终允许"（有些系统版本不会弹出则忽略）
  • 在首次打开 QuizMate 进入笔试进行截图时，系统会弹出授权框，请选择"打开系统设置"，打开 QuizMate 的开关，退出重新打开 QuizMate 即授权完成
  • 在首次打开 QuizMate 进入面试助手-测试模式时，系统会弹出授权框，请选择"允许"即授权完成

Mac 双机协作（2026.09.12）：在客户端选择「双机协作」，使用手机扫描二维码或输入 6 位连接码配对。配对后可在手机端进行三张截图搜题或启动面试，桌面端会同步题目和答案；切回 PC 工作区前请先停止双机协作并确认手机已退出。

  • 演示模式会使用麦克风和电脑声音；正式模式仅采集电脑声音。首次使用请在「系统设置 → 隐私与安全性」中允许 QuizMate 的屏幕录制、麦克风和电脑声音权限。
  • 若二维码失效，可改用 6 位连接码重新配对；退出账号或切换工作区后，按页面提示清理手机会话和本机权限状态。

Mac 客户端安装、权限、双机配对、截图和面试模式的完整步骤请下载Mac 操作手册（2026.09.12）。

四、笔试助手

4.1 启动与配置

打开 QuizMate 客户端，在左侧导航栏选择「笔试助手」，进入笔试设置界面。

  1. 点击「开始使用」按钮启动笔试悬浮窗
  2. 悬浮窗启动后，会显示在屏幕上方，可通过拖拽顶部提示栏移动位置
  3. 拖动悬浮窗四边或四角可调整大小
  4. 使用「悬浮框显示」开关或快捷键可显示/隐藏悬浮框
  5. 透明度可通过进度条实时调节，建议设置为 85% 左右

工作模式

笔试助手支持悬浮框文字呈现模式：截图后答案显示在防捕获悬浮框中，适合单机位笔试场景。

悬浮框主题

提供黑色主题和白色主题两种选择。推荐使用白色主题，在不同背景下都有较好的可读性。

4.2 快捷键说明

QuizMate 支持自定义快捷键，所有快捷键均可在笔试助手页面重新绑定：

快捷键功能默认按键说明
截图识别Ctrl+S截取屏幕区域，AI 识别题目并生成答案
显示/隐藏悬浮框Ctrl+B切换悬浮框的显示和隐藏状态
重新截图Ctrl+R重新截取上次区域

所有快捷键均可点击「更改」按钮自定义，支持 Ctrl/Shift/Alt 组合键。如遇快捷键冲突会提示，可重置为默认值。

4.3 注意事项（重要）

⚠️ 重要提醒
当你完成笔试后，hover 在最右侧的设置按钮，点击「退出笔试助手」可以立即退出。但一定要注意，如果在笔试中途退出了笔试助手，那么你需要打开 QuizMate 客户端才能重新启动，这个过程中，可能会检测到你鼠标切换焦点，如果你在共享屏幕，那么对方也能看到客户端的界面！

所以，除非你确定后面的时间内不再使用笔试助手，否则请不要在笔试中途退出。如果你只是想要隐藏笔试助手的界面，可以随时使用快捷键 Ctrl+B 切换。

五、面试助手

5.1 启动与配置

面试助手可以实时听写面试官的问题，AI 秒出参考答案，并结合你的简历作答，窗口隐身防录屏。

  1. 在左侧导航栏选择「面试助手」，进入面试配置界面
  2. 设置面试上下文：填写应聘岗位和面试公司，选择答案风格（简洁要点/详细展开）
  3. 点击「启动悬浮窗」打开面试答案显示窗口
  4. 点击「开始听写」启动语音识别，系统将自动监听面试官的提问
  5. 识别到问题后，AI 会自动生成参考答案并显示在悬浮窗中

语音模型配置

语音模型 API 由管理后台统一配置，客户端无需本地配置，便于统一更新与计费。

长语音与失败重试

Windows 面试助手会把同一轮连续语音的多个识别片段合并后再提交，片段中的句号或问号不会立即把长问题拆成多次 AI 请求。说完后请留出短暂静音，系统会在静音、停止听写或重连时提交最后一段完整问题。

  • 长问题只生成一张问题卡和一次 AI 请求，避免答案被中间片段打断。
  • 岗位描述、简历和历史面试内容过长时，系统会保留关键信息并压缩请求上下文，降低调用超时或输入过大的概率。
  • 网络失败时可重试当前问题；重复识别片段不会重复创建任务或重复扣费。

语音播报

可开启/关闭语音播报功能。开启后，AI 生成的答案将通过语音朗读出来，方便你在面试中快速获取参考。

快捷键

使用 Ctrl+Shift+I 可快速切换语音听写的开始/停止。

🛡️ 隐身保护
隐身保护已启用：悬浮窗对屏幕共享、录屏软件、远程桌面不可见，可放心使用。

5.3 简历上传

面试助手支持上传简历，AI 将结合你的经历生成更精准的答案：

  • 支持 txt/md 格式简历上传（PDF/Word 需后端解析）
  • 可上传多份简历，选择一份作为当前作答依据
  • 上传后，AI 会在回答时参考你的项目经历、技能等信息

5.4 历史记录与面经分享

面试过程中的所有 QA 记录会保存在历史记录中，方便你复盘。面试结束后，可点击「生成面经」将 QA 记录导出为图片分享。

六、AI 网申自动化插件

AI 网申简历助手以 Chrome/Edge 插件形式运行，使用 QuizMate 统一账号和积分。它负责识别简历、维护岗位模板、理解当前页面字段并执行填写，不会替你提交网申。

6.1 使用流程

  1. 安装插件并登录：从下载页获取 Chrome/Edge 扩展包，加载根目录后登录 QuizMate 账号。
  2. 打开简历工作台：点击插件弹窗中的「打开简历工作台」，上传中文或英文 PDF、Word、TXT 或图片简历。
  3. 命名并核对模板：按公司、岗位或语言自定义模板名称，核对基础字段以及多段教育、实习、工作和项目经历。
  4. 进入网申页面：打开国央企、互联网企业或外企招聘页面，点击页面右下角的插件悬浮按钮。
  5. 选择模板并填写：选择合适模板，点击「AI 填写当前页面」。AI 会匹配文本、下拉、单选、多选和级联字段。
  6. 处理待确认字段：识别不到的特殊字段可在侧边栏补录，选择只写入当前页面或保存到模板，并多选同步至其他模板。

6.2 档案管理

档案分为以下字段组，支持多份档案管理：

  • 基本信息：姓名、性别、出生年月、籍贯、政治面貌、民族、身份证号
  • 联系方式：手机号、邮箱、微信号、紧急联系人
  • 教育背景：毕业院校、专业、学历、毕业时间、GPA、年级排名、英语等级
  • 求职意向：意向岗位、意向城市、期望薪资、到岗时间、实习时长、每周到岗天数
  • 多段经历：教育、实习、工作、项目、校园活动、家庭成员、获奖与培训分别以子表格保存，不会把多段经历合并。
  • 英文网申：上传英文简历后保留姓名、学校、公司、岗位、项目等英文原文，并优先匹配英文页面选项。
💡 小贴士
支持文本框、下拉框、单选、多选和级联筛选等常见控件。自动化网申承诺永久免费；注册赠送的积分可用于体验 QuizMate 笔试与面试辅助。

七、简历制作

简历制作模块支持多份简历管理、AI 按 JD 适配优化、模板美化、导出 PDF。

7.1 核心功能

上传简历

支持上传已有简历文件，系统自动解析入库

AI 优化

粘贴目标岗位 JD，AI 针对性优化简历关键词和经历描述

JD 适配生成

选择 1-N 份简历 + 目标 JD，AI 综合生成全新适配简历

导出 PDF

多套模板可选，一键导出精美 PDF

7.2 使用流程

  1. 点击「新建简历」或「上传简历」开始
  2. 填写基本信息（姓名、手机、邮箱、学历、专业）
  3. 编辑各章节内容（教育背景、实习经历、项目经历、技能证书、荣誉奖项等）
  4. 选择模板样式
  5. 可选：粘贴目标岗位 JD，使用 AI 优化简历内容
  6. 保存后点击「导出 PDF」生成最终简历

八、常见问题

Q1：QuizMate 会被笔试/面试平台检测到吗？

不会。QuizMate 利用系统级窗口隔离技术，对屏幕共享、录屏软件、远程桌面均不可见。已有 2 千多位用户正常使用，未有检测反馈。请在使用前参照测试检查章节进行验证。

Q2：积分用完了怎么办？

点击客户端或官网的积分入口，进入充值中心购买积分套餐。网申助手与 QuizMate 笔试、面试功能共用同一账户、积分余额和订单记录。

Q3：支持哪些操作系统？

Windows 系统需不低于 2004 版本号（2020 年 4 月后的系统版本），Mac 系统需不低于 macOS 15.0。

Q4：安装时被安全软件拦截怎么办？

请关闭 360 等"安全软件"后再次尝试。QuizMate 需要调用特定的系统 API 以实现"隐身"能力，可能会触发部分安全软件的提醒。我们使用的是标准的系统能力，请放心使用。

Q5：笔试中途可以退出笔试助手吗？

可以，但不建议在笔试中途退出。退出后需要重新打开 QuizMate 客户端才能重新启动，过程中可能检测到鼠标焦点切换。如果只是想隐藏界面，请使用快捷键 Ctrl+B 切换显示/隐藏。
