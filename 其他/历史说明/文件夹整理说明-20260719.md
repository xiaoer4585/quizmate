# 考试插件文件夹说明（2026-07-19）

根目录已按产品职责整理为七个正式模块：

1. `官网模块`：QuizMate 正式官网、Watch 网页端和部署资料。
2. `运营管理`：管理后台、宣传、运营、交付和品牌资料。
3. `测试文档`：接口、充值、Windows、安卓和自动化测试证据。
4. `安卓端`：当前有效的新一代安卓源码。
5. `window客户端`：当前 Windows 源码、正式安装包和浏览器插件。
6. `mac客户端`：后续 macOS 客户端预留位置。
7. `注册登陆模块（包含充值）`：通用账号、会话、积分、充值、支付和统一入口底层。

旧项目、旧安装包、CloudBase 回退资料、实验工具和临时文件均保留在 `归档以备万一`，未删除。

`windows2.0` 仅保留本任务工作区自身的隐藏配置及两个被运行环境占用的历史构建残留；当前有效代码已经移入正式分类，不再从该目录开发。

`.agents`、`.codex`、`.deps`、`.workbuddy`、`.codebuddy`、`.git`、`config` 等属于本机开发工具元数据，保留在根目录，不属于产品模块。

详细移动关系见 `目录迁移清单-20260719.md`。
