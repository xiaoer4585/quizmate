# 考试插件目录迁移清单（2026-07-19）

## 正式模块

- `官网模块`：QuizMate 官网、Watch 网页端及部署资料。
- `运营管理`：宣传运营资料与管理后台。
- `测试文档`：自动化测试证据、Windows/安卓/注册充值测试资料。
- `安卓端`：当前有效的 `QuizMate-Android` 新一代源码。
- `window客户端`：当前 Windows 源码、正式安装包及浏览器插件。旧序列号配套页面已移入归档，不参与现行积分账户流程。
- `mac客户端`：预留目录，当前无产品代码。
- `注册登陆模块（包含充值）`：阿里云通用账号、登录、积分、充值、支付与统一网关底层；CloudBase 兼容源码仅保留作回退。

## 归档规则

- 旧安卓、旧浏览器插件、旧 Windows 工程、历史整包、实验工具和临时部署文件统一移动到 `归档以备万一`。
- 不删除 CloudBase 源码、历史数据导出或旧安装包。
- `.agents`、`.codex`、`.deps`、`.workbuddy`、`.codebuddy`、`.git` 等隐藏开发环境目录保留在根目录，避免破坏本机开发工具。

## 当前有效入口

- Windows 源码：`window客户端/QuizMate-Windows`
- Windows 安装包：`window客户端/发布包/QuizMate Setup 2025.11.16.exe`
- 安卓源码：`安卓端/QuizMate-Android`
- 浏览器插件：`window客户端/浏览器插件/当前版本-1.2.8`
- 官网：`官网模块/正式官网-quizmate.vip`
- Watch 网页端：`官网模块/辅助页面-watch-web`
- 通用后端：`注册登陆模块（包含充值）/阿里云后端-quizmate-api`
