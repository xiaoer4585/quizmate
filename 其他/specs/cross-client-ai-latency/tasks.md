# 三端 AI 调用提速与本地知识库实施清单

## 执行规则

- 每完成一项即更新勾选状态和测试证据。
- P0/P1、兼容或回滚门禁失败时停止生产发布。
- 不删除历史服务端知识库数据。
- 不修改浏览器插件源码。
- macOS 没有真实 Mac 签名、公证和启动证据时必须标记阻塞。

## 2. 先补自动化测试

- [x] 2.1 补主 API 测试
  - 验证分析路径不查询知识库表。
  - 验证响应固定 `usedKnowledge=false`、`knowledgeHits=[]`。
  - 验证知识库兼容动作鉴权后零数据库写入。
  - 保持成功一次扣分、失败不扣分和幂等测试。
  - _需求：2、6_

- [x] 2.2 补网关测试
  - 覆盖上传票据签发、篡改、过期、对象不匹配和旧协议兼容。
  - 覆盖 OSS 受管对象读取、OCR 达标直通、OCR 不达标单次视觉回退。
  - 覆盖阶段耗时日志脱敏。
  - _需求：5、6_

- [ ] 2.3 补三端测试
  - Electron 覆盖本地文件添加、恢复、账号隔离、删除和 IPC 路径安全。
  - Android 覆盖应用私有目录复制、索引、账号隔离和删除。
  - 三端覆盖无知识库网络动作、图片压缩边界、`objectKey/uploadTicket/requestId` 请求字段。
  - _需求：1、3、4_

## 3. 实现主 API 知识库空化

- [x] 3.1 移除分析知识库查询和提示词拼接
  - 删除 `findKnowledge` 调用和模型知识上下文构造。
  - 保持数据库 schema 不变，使用日志固定 `used_knowledge=false`。
  - _需求：2_

- [x] 3.2 改造知识库兼容动作
  - 用户上传、列表、删除改为鉴权后的空实现。
  - 管理端列表、删除改为管理员鉴权后的空实现。
  - 不解析文件、不写数据库、不删除历史记录。
  - _需求：2_

## 4. 实现网关提速

- [x] 4.1 实现短期上传票据
  - 新增 HMAC 票据签发与校验模块。
  - 新客户端凭票据跳过网关第二次资料查询。
  - 无票据旧客户端保留原验证路径。
  - _需求：3、5_

- [x] 4.2 实现 OSS 内网读取
  - 公网客户端只用于签发 PUT 地址。
  - 内网客户端按受校验 `objectKey` 读取图片。
  - 阻止路径穿越、错误前缀和对象不匹配。
  - _需求：5_

- [x] 4.3 实现 OCR 优先路由
  - Tesseract 输出文字与置信度。
  - 达标直接调用主 API；不达标仅回退一次 VLM。
  - 保持失败不扣积分。
  - _需求：5、6_

- [x] 4.4 增加分段耗时
  - 网关和主 API 记录脱敏阶段耗时。
  - 响应保持旧客户端可解析，不泄露秘密和内容。
  - _需求：6_

## 5. 实现 Windows 与 macOS 本地知识库

- [x] 5.1 实现共享数据结构和主进程存储

  - _需求：1_

- [x] 5.2 实现安全 IPC 和界面
  - 增加选择、添加、列表和删除 IPC。
  - 设置页显示本地文件及“不会参与 AI”说明。
  - Windows 与 macOS 对应实现保持一致。
  - _需求：1_

- [x] 5.3 优化桌面分析请求
  - 立即显示处理状态并取消必经积分预查。
  - 使用稳定 `requestId`、`objectKey` 和 `uploadTicket`。
  - 统一最长边、JPEG 质量和体积目标。
  - _需求：3、4、5_
