# 独立手机测试服务（尚未部署）

这份服务只用于 Windows PC+手机功能联调。运行需要 Node.js 22 和一个带有效 HTTPS 证书的独立测试入口。正式官网、自动更新和正式 API 服务不需要替换。

## 启动配置

部署目录中放置 `server.mjs`、`phone.html`。不要部署 `preview.mjs`，它只是假数据界面预览。

必填环境变量 `RELAY_PUBLIC_URL`：手机可访问的 HTTPS 地址，例如 `https://your-test-host.example/companion/`。PC 页面填写同一地址。

可选环境变量：

- `HOST=127.0.0.1`、`PORT=8235`：仅本机监听，前面接 HTTPS 反向代理。
- `RELAY_DATA_DIR`：独立可写私有数据目录，禁止作为网站静态目录。密钥与加密会话文件保存在其中，备份时必须一起保存。
- `RELAY_AUTH_ENDPOINT`：默认既有账号 API。若使用专用测试账号后端，可指定该后端地址。

启动：`node server.mjs`。测试：`node --test server.test.mjs`。

反向代理将 `/companion/` 原样代理到 `http://127.0.0.1:8235`，关闭缓存，限制请求体 100 KB；不要把服务源码或私有数据目录作为静态网站。`/companion/health` 返回 `ok`。

## 实际数据与积分

手机通过测试服务调用原登录接口，电脑和手机必须使用同一个账号，各自保有独立登录会话。登录、查询余额和退出会访问原账号服务，但转发结果不会执行扣分。截图分析、面试回答仍由 Windows 调用原 AI 接口并按原规则扣除真实积分；请使用专门的测试账号。

结果最多保留 200 张卡片、会话有效期 24 小时；配对码 5 分钟，一次使用。服务存储登录令牌的哈希，结果文件加密。手机不接收原始截图、音频或简历附件；生成答案本身可能引用简历内容。

## 当前测试版边界

采用 2 秒轮询和完整卡片快照。PC 待同步队列仅在内存中，重启/断开配对会清理；因此还不满足原完整方案的持久发件箱和 AI/扣分/结果事件事务原子性。模型请求已扣分但网络返回丢失时，本版不保证找回答案，面试不自动重试以防重复收费。

不能将本服务称为已上线或已完成真实双端验收。需要先在独立测试环境启用，再用实机测试截图、声音、跨模式快捷键、断网恢复、退出登录和积分流水。

## 停止及回滚

停止独立 Node 进程，移除该测试入口的代理配置；正式 API 和数据库结构没有迁移。测试会话数据按需从独立私有目录清除，不能清理原账号、积分或 PC 客户端数据。
