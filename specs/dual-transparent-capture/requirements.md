# 双机协作笔试屏幕透明区截图

## 问题与范围

双机协作笔试时，部分用户不能触碰键盘，因此需要一种完全用鼠标触发截图搜题的方式。功能只属于 Windows 双机协作笔试工作区；PC 笔试、PC 面试、双机协作面试和语音播报模式保持现有行为。

## 用户故事

- 作为不能触碰键盘的笔试用户，我可以选择屏幕透明区截图模式，用鼠标单击固定的透明正方形完成截图和搜题。
- 作为双机协作笔试用户，我可以进入调整状态移动屏幕透明区并用四角调整其正方形大小，完成后区域恢复完全透明。
- 作为使用快捷键的用户，我可以继续使用原有快捷键和最多三张截图合并搜题。
- 作为双机协作用户，我希望每次单击屏幕透明区的答案仍通过现有同步通道显示在第二机位，并且本地截图在提交后清空。

## 验收标准（EARS）

1. 当用户进入双机协作笔试页面时，客户端应显示“快捷键截图”和“屏幕透明区截图”两个互斥模式；默认选择快捷键截图。
2. 当用户选择屏幕透明区截图模式且双机工作区已启用时，客户端应创建一个完全透明、无阴影、正方形、可接收鼠标点击的窗口；该窗口不应出现在 Windows 截图、录屏或投屏中。
3. 当屏幕透明区被单击时，客户端应只发起一次全屏截图和一次搜题请求；搜题成功或失败后都应清空本次截图，下一次单击开始新的截图搜题轮次。
4. 当屏幕透明区截图模式运行时，双机笔试截图和搜题快捷键应被忽略，复制答案快捷键仍可用；切回快捷键模式后原快捷键应恢复。
5. 当屏幕透明区截图搜题成功时，系统应复用现有双机 relay 卡片通道，将答案显示在第二机位，并沿用现有积分、鉴权和错误处理。
6. 当用户进入配置模式时，主客户端应持续显示半遮蔽等待面板，透明正方形应允许直接拖动主体改变位置、拖动四角等比例调整大小；只有用户点击“完成调整”后才返回客户端正常界面。
7. 当用户退出双机协作、断开手机或切换到其他助手时，屏幕透明区窗口应立即隐藏且不能继续触发截图。
8. 当透明窗口的 Windows 防捕获保护无法验证时，客户端应保持窗口隐藏，并提供客户端或托盘操作反馈。
9. 当应用重启时，客户端应恢复最近保存的触发模式、透明窗口位置和正方形边长；如果保存的显示器不可用，应将窗口回退到当前主显示器工作区。
10. 当用户使用快捷键模式时，现有三张截图、快捷键、PC 悬浮框、面试助手和双机面试行为应保持不变。
11. 当透明正方形处于正式使用状态时，短按应触发一次截图搜题；按住并拖动超过阈值应只移动位置，不触发截图搜题。

## 非目标

- 屏幕透明区截图模式不支持多次点击累积截图。
- 本次不改变后端 AI、积分和 relay 协议，只增加可选的客户端触发来源状态。
- 本次只构建 Windows 测试包，不构建 macOS、不上传、不上线。
