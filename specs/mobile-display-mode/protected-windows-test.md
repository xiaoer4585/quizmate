## 界面和运行边界

- Windows 导航为 PC笔试助手、PC面试助手、双机协作笔面试，删除原积分/AI徽标。
- 双机开始为绿色，运行后的“停止双机协作”为红色，处理截图期间仍可停止。手机面试开始/结束同样红绿区分。
- PC 两种助手之间保留既有并行及切换；任何 PC 助手运行时阻止进入双机页面，按实际状态提示关闭其中一个或两个。双机运行阻止进入 PC 助手页，显示“请先关闭双机协作笔面试”。菜单、工作台入口、历史路由以及主进程操作共同守卫。
- 双机内 Alt+Q 截图和 Alt+R 面试均有效，可沿用原快捷键设置自定义；只有当前工作区收到操作。演示模式采集麦克风和系统声音，正式模式只采集系统声音，沿用 PC 提醒颜色和岗位/简历。
- 手机阅读顶栏为 38px 加安全区，仅品牌、连接状态、余额；答案区独立滚动，保留字体、夜间、来源筛选及紧凑上一题/下一题。无“手机阅读”“本次记录”、复制、底部说明、退出、断开按钮。
- 页面关闭尽力发出撤销请求；浏览器不能保证关闭事件送达，服务用 90 秒阅读心跳租约兜底。刷新重新登录；锁屏或后台超过租约可能需要重新登录、配对。配对断开后手机面试停止，工作区仍保持双机，防止快捷键误入 PC。

## 核心保护边界

Windows 构建将 InterviewHelper / RealtimeVoiceHelper 替换为专用适配器，macOS 保留原实现。原问题判断、转写合并与停顿提交、残句等待、上下文裁剪和问题队列在独立服务执行。客户端仅采集、传输、渲染和管理本地资源。

ASR 连接先获得 30 秒一次性票据，代理向语音供应商建立连接并注入长期密钥，Windows 不再调用 getAsrConfig、不接收该密钥。限制账号并发、票据签发频率、帧大小和连接时长，定期校验账号。接口按登录身份验证，序号使转写重发幂等；AI 请求遇到未知结果不自动重试。阅读与同步不额外扣积分，原 AI 接口继续负责结算。

发布构建压缩且关闭 source map；audit-protected-build.cjs 拒绝原策略标识、长期密钥接口及源码映射。服务源文件不包含在安装包。**这不是不可逆的代码加密**：本地 UI、截图、音频采集、协议和可观察的产品流程仍可逆向或仿制。迁移的策略不再随新包分发，提升保护程度，但不能承诺无法复刻系统设计。

GitHub 仓库已验证为私有。历史公开副本无法收回；Gitee 可见性尚未确认。旧生产客户端兼容所需的 getAsrConfig 接口本次未关闭，因此不能宣称生产旧版密钥路径已消除。彻底收口需要兼容迁移、旧接口退役与供应商密钥轮换的单独发布。
