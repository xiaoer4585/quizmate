# 注册登录与充值通用底层

本目录是可被多个产品复用的账号与商业化底层，负责注册、登录、会话、积分、充值、支付回调和统一 API 入口。

- `阿里云后端-quizmate-api`：当前生产后端及数据库迁移。
- `阿里云统一入口-study-auth-api`：当前生产兼容入口，负责截图转存 OSS、旧客户端兼容和请求转发。

产品专属客户端调用代码、网页页面和管理界面不放在本目录，分别位于对应产品模块和 `运营管理`。

历史 CloudBase 云函数已移入 `归档l历史代码正常不需要引用`，不参与生产请求、构建或发布。

生产密钥不得写入源码；阿里云 AccessKey、支付密钥、邮件密码和模型密钥必须通过服务器环境变量或加密配置保存。
